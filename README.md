# Inverse Heat Transfer with Physics Informed Neural Networks (PINNs)


We improve a SciML paper on Inverse Heat Transfer using PINNs 

The link for paper can be found <a href="https://www.sciencedirect.com/science/article/pii/S2352492823010279" target="_blank">here</a>

<i>It is advised to first go through the above paper before further diving deep on this repository. </i>

The ground data generation, methodology and results for improvement can be found in `report.pdf` .


## Project Structure

```text
this-project/
├── Dataset/
│   ├── const_pinn_data.npz
│   ├── const_pinn_data_noisy.npz
│   ├── linear_data_improved.npz
│   ├── linear_data_noisy_improved.npz
│   ├── sinusoidal_data_improved.npz
│   └── sinusoidal_data_noisy_improved.npz
├── README.md
├── GT.ipynb
├── iht_with_pinn.ipynb
└── report.pdf
```


`GT.ipynb` : this is used to generate ground truth data for training.

`iht_with_pinn.ipynb` : this is the main file where PINN is trained and tested.

`report.pdf` : this contains detailed report — from problem statement,data generation, methodology to result.

`Dataset` : These are $(x,t,T)$ triplets ( generated by different sources of heat ) which will be used as $(x,t)→T$ in PINN training.

<b> NOTE 1 : </b> In codes, you might have to look at the file path before running, as these were run on colab and kaggle, so path changes accordingly.

<b> NOTE 2 : </b> The Appendix is seperated from the report. You can request if you need.
